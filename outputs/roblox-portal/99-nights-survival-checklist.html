Why this order works

Beds and missing-child rescues improve day progression, so early work on both reduces the number of repeated night cycles. Daylight should be used for purposeful searches, while the camp fire and emergency stock protect the run from a late return.

Solo adjustment

In solo play, shrink the search radius and use one objective per daylight window. In a group, split roles but keep a shared return time. A larger team does not help if every player is caught away from camp at night.

Sources and limits

The checklist uses the official game premise and mechanics reviewed in current guide coverage, including beds, missing children, camp resources, classes bought with Diamonds, daylight searching, and friend roles. Exact balance can change after updates.
